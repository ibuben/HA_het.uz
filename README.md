# HET.uz для Home Assistant

Интеграция для получения данных из личного кабинета потребителя электроэнергии [HET.uz] (https://www.het.uz/) («Hududiy Elektr Tarmoqlari»).
Данная интеграция предназначена для абонентов региональной электросети Республики Узбекистан, подключенных к АСКУЭ и имеющих доступ в кабинет het.uz.

## Разработано на общественных началах в eXUnity LAB

## Возможности

Интеграция создаёт следующие сенсоры:

| Сенсор | Описание |
|--------|----------|
| Баланс | Текущий баланс счёта (сум) |
| Показания счётчика | Последние показания (кВт·ч) |
| Дата показаний | Дата последних показаний |
| Последний платёж | Сумма последнего платежа (сум) |
| Дата последнего платежа | Дата последнего платежа |
| Потребление за текущий месяц | Расчётное потребление за месяц (кВт·ч) |
| Начисление за текущий месяц | Расчётная сумма за месяц (сум) |
| Потребление за месяц (эко-тариф) | Потребление по эко-тарифу (кВт·ч) |

Данные обновляются автоматически с настраиваемым интервалом (по умолчанию 30 минут). Токен авторизации кэшируется для снижения нагрузки на API.

## Установка через HACS

1. Убедитесь, что [HACS](https://hacs.xyz/) установлен в Home Assistant.
2. Откройте HACS → **Integrations** → три точки → **Custom repositories**.
3. Добавьте репозиторий `https://github.com/ibuben/HA_het.uz`, категория **Integration**.
4. Найдите **HET.uz** в HACS и установите.
5. Перезагрузите Home Assistant.
6. Перейдите в **Settings → Devices & Services → Add Integration** и найдите **HET.uz**.

## Ручная установка

1. Скопируйте папку `custom_components/het_uz` в каталог `config/custom_components/` вашего Home Assistant.
2. Перезагрузите Home Assistant.
3. Добавьте интеграцию через UI.

## Настройка

При добавлении интеграции потребуются:

- **Номер счёта** — логин от личного кабинета HET.uz
- **Пароль** — пароль от личного кабинета

После настройки можно изменить интервал обновления через **Configure** в карточке интеграции (от 5 минут до 24 часов).

## API

Интеграция использует официальное мобильное API личного кабинета:

- Авторизация: `POST /household-consumer/v1/mobile-cabinet/user-login`
- Данные: `GET /household-consumer/v1/mobile-cabinet/consumer-state`
